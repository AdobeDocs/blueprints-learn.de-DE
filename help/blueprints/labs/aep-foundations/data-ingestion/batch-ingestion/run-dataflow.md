# Datenfluss ausführen

Wenn alles gut aussieht, klicken Sie auf die Schaltfläche **Beenden** oben rechts, um das Laden der Daten auszuführen.

Nachdem Sie auf **Beenden** geklickt haben, gelangen Sie zurück zum Bildschirm **Datenflüsse**. Es sollte einige Minuten dauern, bis der Datenfluss erstellt ist. Der erste Durchgang sollte in ein paar Minuten beginnen.

![Datenflussbildschirm mit dem neu erstellten Datenfluss und dem Ausführungsstatus](assets/run-dataflow-dataflows-sources-screen.png)

>[!NOTE]
>
>Sie müssen die Seite kontinuierlich aktualisieren, um die Statusaktualisierung anzuzeigen, da das Backend keine Aktualisierungen an die Benutzeroberfläche sendet.

>[!NOTE]
>
>Wenn Sie alle Warnhinweise aktiviert haben, erhalten Sie einen Warnhinweis in Ihrem Browser in der oberen rechten Ecke Ihres Browsers, wenn der Fluss zu laufen beginnt und erfolgreich abgeschlossen wird oder fehlschlägt
