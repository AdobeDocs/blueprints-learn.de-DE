# Schema erstellen

## Schemaassembly

Alle Schemas in XDM werden auf die gleiche Weise zusammengestellt.  Ein Schema besteht immer nur aus einer Klasse und einer oder mehreren Feldergruppen. Darüber hinaus bestimmt die Klasse eines Schemas, wie andere Systeme innerhalb der Experience Platform die Daten interpretieren (d. h. als datensatzbasierte oder Zeitreihen).

![Diagramm mit einem Schema, das aus einer Klasse und einer oder mehreren Feldergruppen besteht](assets/overview-schema-assembly.jpeg "Schemaassembly")
