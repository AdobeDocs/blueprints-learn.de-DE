# Laborübung

**Sie benötigen Folgendes, bevor Sie beginnen:**

- Zuordnen von Anwendungsfällen zur Architekturarbeitsmappe - [Arbeitsmappe unten drucken]
- Stift, Bleistift oder Textmarker

Datei herunterladen — [Zuordnungsfunktionen zu Architecture Exercise.pdf](assets/lab-exercise-mapping-capabilities-to-architecture-exercise.pdf)

**Für jeden der drei Anwendungsfälle der 5G-Verbindung werden Sie Folgendes tun:**

- Nutzungsszenario-Kurzbeschreibung und Anhang lesen
- Beantworte die fünf kritischen Denkfragen
- Umkreisen oder markieren Sie die erforderlichen AJO-Architekturkomponenten.
- Abschließende Empfehlung der Orchestrierungs-Engine

Bearbeiten Sie alle drei Anwendungsfälle und sehen Sie sich dann das Video an, wenn Sie fertig sind.
