# Zuordnen von Anwendungsfällen zur Architektur

## Lernziele

Am Ende dieses Labors werden Sie in der Lage sein,

- Anwendung eines strukturierten Entscheidungs-Frameworks zur Bewertung realer Marketing-Anwendungsfälle
- Identifizieren Sie die AJO-Architekturkomponenten, die zur Unterstützung jedes Anwendungsfalls erforderlich sind
- Wählen Sie die entsprechende Orchestrierungs-Engine - Orchestrierte Kampagnen oder Journey - und begründen Sie Ihre Empfehlung
- Erläuterung der richtigen Architekturentscheidungen für alle drei Anwendungsfälle für die 5G-Verbindung und Erläuterung der Signale, die für jeden dieser Anwendungsfälle ausschlaggebend waren

Wenn Sie bereit sind, fahren Sie mit dem Video fort, um Anweisungen für das Labor zu erhalten.
