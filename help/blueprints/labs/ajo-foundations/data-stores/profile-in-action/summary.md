# Zusammenfassung

In diesem Labor haben Sie einen Datenstrom konfiguriert und ein simuliertes Web-Ereignis mithilfe von Postman an die Edge Network gesendet, um zu beobachten, wie Daten durch Adobe Experience Platform fließen.

Sie haben bestätigt, dass das Ereignis von mehreren Platform-Services verarbeitet wurde, indem Sie bestätigt haben, dass im Echtzeit-Profil ein Profil erstellt und für ein Segment qualifiziert wurde. Sie haben auch überprüft, ob das Profil in der Edge vorhanden ist, haben bestätigt, dass das Ereignis im Data Lake gespeichert ist, und beobachtet, dass das Profil aufgrund des geplanten Batch-Aktualisierungsprozesses noch nicht im Profil-Snapshot-Datensatz angezeigt wurde.

Durch diese Schritte haben Sie gezeigt, wie Ereignisse die Ebenen Edge, Echtzeit-Profil und Data Lake von Adobe Experience Platform durchlaufen.
