# Relationaler Speicher in Aktion

## Labor-Übersicht

In diesem Video erfahren Sie, wie der relationale Store mit dem Echtzeit-Kundenprofil integriert wird und was Sie in diesem Labor tun werden, um relationale Schemata zu durchsuchen, eine Dimension für Profilziele einzurichten und eine orchestrierte Kampagne zu erstellen und zu testen.

>[!VIDEO](https://video.tv.adobe.com/v/3486539/)

## Lernziele

- Durchsuchen von Schemata und Anzeigen von Beziehungen
- Einrichten einer Target-Profil-Dimension
- Erstellen einer orchestrierten Kampagne mithilfe einer Vielzahl von Workflow-Aktivitäten
- Eine Zielgruppe mithilfe der Aktivität „Zielgruppe lesen“ erstellen und Attribute aus dem relationalen Schema verwenden
- Testen Sie die Kampagne und verstehen Sie das Verhalten bei der Verwendung von AEP-Zielgruppen in Verbindung mit einem relationalen Schema
